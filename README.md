# type.test

A minimal typing speed test app built with vanilla HTML, CSS and JavaScript.

## Features

- 60 second countdown timer
- Real-time character highlighting — green for correct, red for incorrect
- Live stats — characters per minute and accuracy percentage
- Progress bar
- Three difficulty levels — Easy, Medium, Hard
- Animated preview of the text before the game starts
- Backspace is disabled to keep the challenge fair

## How to use

1. Select a difficulty level
2. Press **Start**
3. Type the text as fast and accurately as you can
4. When the timer hits zero or you finish the text, your results are shown
5. Press **Reset** to go back to the start

## Project structure

```
index.html    — page structure
style.css     — all styles and theming
script.js     — all game logic
```

## Tech stack

- HTML
- CSS
- JavaScript — no frameworks, no libraries

## Running locally

No build tools needed. Just open `index.html` in your browser and you're good to go.
